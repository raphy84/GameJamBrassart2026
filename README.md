// README

You're an old wizard looking to grow a magic plant ! Take care of it based on what it demands of you, between spells and the water can.
If you do well enough, it might grow into Something spectacular...


CONTROLS :

To move : Left joystick
Confirm : Click
Grab item : Trigger 

TUTORIAL :

The plant will demand different actions to grow to the next phase. Give it the appropriate items and execute the correct spells to make it grow.

Each phase, the plant will demand more objects and spells to be done. You have a limited time to make it grow to its final phase, so be efficient enough to see it grow.
You get points at each growing phase completed.
